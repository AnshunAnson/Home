# Agent 审计（Audit）是什么

> [!ABSTRACT]+ 摘要
>对 Agent 的执行过程进行**监督、核查、溯源、校验**的行为。

### 📝 可审计（Auditable）

指 AI Agent 的**全流程行为透明、可留痕、可追溯**，所有操作、决策、调用都能被完整记录与核验，不是黑盒执行。

## 💡 核心特征

- 思考链、工具调用、权限操作、数据流转**全程留痕**
- 行为可复现、决策可解释、责任可定位
- 满足合规、安全、风控的追溯要求

## Agent 审计（Audit）

 - 对 Agent 的执行过程进行**监督、核查、溯源、校验**的行为。
- # 内容：
- 核查 Agent 行为是否合规、是否越权
- 追溯异常行为、错误决策、风险操作
- 校验数据使用安全、多 Agent 协作链路
- 定位问题责任、优化 Agent 逻辑
