# 设计比赛 - HMI 概念效果

## 📌 一句话定义

基于 UI 需求输出 HMI 概念效果视频，使用 Niagara 粒子自定义变换和半透明描边材质。

## 🎯 项目目标

- 基于 UI 需求制作 HMI 概念效果
- 输出展示视频
- 粒子特效与材质结合

## 💼 职责与业绩

### Niagara 粒子自定义变换
- 粒子系统高级应用
- 自定义模块开发

### 半透明描边材质
- 创新的描边效果实现
- 与 UI 设计结合

## 🛠️ 使用的技术栈

| 技术 | 用途 |
