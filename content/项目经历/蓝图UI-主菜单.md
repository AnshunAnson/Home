# 蓝图UI - 主菜单系统

## 📌 项目目标

使用 Blueprint + UMG 开发游戏主菜单系统，展示 UI 交互和动画能力。

## 🎯 学习/开发内容

### 功能模块
- [ ] 开始游戏菜单
- [ ] 设置面板（画质/声音/控制）
- [ ] 存档选择界面
- [ ] 过渡动画

### 技术点
- [ ] 界面切换动画
- [ ] 数据持久化
- [ ] 设置配置管理
- [ ] 屏幕分辨率适配
