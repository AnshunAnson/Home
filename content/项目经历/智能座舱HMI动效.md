# 智能座舱 Niagara 概念特效

## 📌 一句话定义

为车展概念展示项目制作基于 Niagara 的动效氛围效果，基于 UI 制作的创意图实现粒子特效。

## 🎯 项目目标

- 基于 UI 创意图制作动效氛围
- 实现 Niagara 粒子模拟音波扰动效果

## 💼 职责

### Niagara 动效氛围
- 基于 UI 制作的创意图
- 粒子系统与 UI 效果结合

### SDF 距离场效果
- Niagara 粒子模拟音波扰动
- 基于距离场的波纹效果

## 🛠️ 使用的技术栈

| 技术 | 用途 |
|------|------|
| Niagara | 粒子系统核心 |
| SDF 距离场 | 波纹扰动效果 |
| Blueprint | 粒子模块编写 |
| UI 材质 | 动效素材制作 |
