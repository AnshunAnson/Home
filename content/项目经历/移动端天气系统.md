# PoC UE 动效 - 移动端天气系统

## 📌 一句话定义

移动端高性能 PBR 材质制作，包含流动材质动效和天气系统，实现台架交互 demo 交付。

## 🎯 项目目标

- 移动端高性能 PBR 材质
- 流动材质动效
- 移动端天气系统
- 交付台架交互 demo

## 💼 职责与业绩

### 1. 高性能 PBR 材质
- 移动端渲染性能优化
- 材质实例化技术

### 2. 流动材质动效
- 基于 UI 需求的动态纹理
- 实时流动效果

### 3. 移动端天气系统
- 雨、雪、雾等天气效果
- 与 UI 交互联动

### 4. 台架交互 Demo
- 交付给客户的交互演示

## 🛠️ 使用的技术栈

| 技术 | 用途 |
|------|------|
| UE5 | 引擎与渲染 |
| PBR 材质 | 高性能材质制作 |
