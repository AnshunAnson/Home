# AI 辅助开发流程

> **核心理念**: 用 AI 工具驱动开发，不依赖传统学习

## 🎯 Vibe Coding 工作流

```
需求 → AI Prompt → 生成代码 → AI 审查 → 调试优化 → 完成
```

### 1️⃣ 需求阶段

- 描述你想要实现的功能
- 不需要知道如何实现，AI 会帮你想

### 2️⃣ AI Prompt 阶段

- 清晰描述需求
- 指定技术栈 (UE5, Blueprint, UMG)
- 说明约束条件

### 3️⃣ 代码生成阶段

- 让 AI 生成初始代码
- 不满意就重新生成
- 多尝试不同的 prompt

### 4️⃣ AI 审查阶段

- 让 AI 检查代码问题
- 让 AI 提供优化建议
- 让 AI 解释不理解的代码

### 5️⃣ 调试优化阶段

- 在 UE5 中测试
- 遇到问题问 AI
- 让 AI 帮你 debug

---

## 🤖 常用 AI 命令

### 代码生成

```
帮我用 Blueprint 实现一个 HUD 血条系统
包含：血条、蓝条、能量条
风格：科幻 UI
```

### 代码审查

```
帮我审查这段 Blueprint 代码
找出潜在问题并提供优化建议
```

### 调试帮助

```
我在 UE5 中遇到了这个问题：
[粘贴错误信息]
帮我分析原因并提供解决方案
```

### 学习辅助

```
解释这个 Blueprint 节点的作用：
[粘贴截图或描述]
不需要深入原理，只需要知道怎么用
```

## 📊 Vibe Coding vs 传统学习

| 传统方式 | Vibe Coding |
|----------|-------------|
| 先学 C++/Blueprint | 先让 AI 生成代码 |
| 看书/文档 | 直接问 AI |
| 理论扎实 | 快速出成果 |
| 学习周期长 | 边做边学 |
