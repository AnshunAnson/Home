# Prompt 工程实践

> **核心理念**: 好的 Prompt = 好的结果

## 🎯 Prompt 基本结构

```
角色 + 任务 + 约束 + 输出格式
```

### 示例

```
你是一个 UE5 Blueprint 专家。
帮我创建一个背包系统，包含以下功能：
1. 格子式背包 UI
2. 物品拖拽
3. 数量显示

输出格式：
- Blueprint 节点结构
- UMG 布局建议
- 注意事项
```

---

## 📝 UE5 开发常用 Prompt 模板

### 1. 代码生成

```
你是一个 UE5 开发专家。
帮我用 Blueprint 实现 [功能描述]。
要求：
- 使用 UMG
- 考虑性能
- 包含错误处理

输出代码并解释关键部分。
```

### 2. 代码优化

```
帮我优化这段 Blueprint 代码：
[粘贴代码]

目标：
- 提升性能
- 减少节点数量
- 提升可读性
```

### 3. 问题诊断

```
我在 UE5 中遇到了这个问题：
[粘贴错误信息/截图描述]

请帮我：
1. 分析可能的原因
2. 提供解决方案
3. 给出预防建议
```

### 4. 学习解释

```
向我解释 UE5 中的 [概念/功能]。
我不需要深入原理，只需要知道：
- 什么时候用
- 怎么用
- 有什么注意事项
```

## 🛠️ Prompt 技巧

### 1. 指定技术栈

```
✅ 使用 UE5.3 + Blueprint
✅ 使用 UMG + Material
```

### 2. 说明约束

```
✅ 移动端性能优先
✅ 需要兼容 VR
```

### 3. 提供示例

```
✅ 类似这样的效果：[参考图片描述]
✅ 类似于《原神》的 UI
```

### 4. 要求解释

```
✅ 请解释关键代码
✅ 告诉我可能的问题
```

## 📊 Prompt 质量对比

| 质量 | Prompt | 结果 |
|------|--------|------|
| 低 | "帮我做 HUD" | 模糊，可能需要多次修改 |
| 中 | "帮我用 UMG 做科幻风格 HUD" | 比较明确 |
| 高 | "帮我用 UMG 做科幻风格 HUD，包含血条蓝条，有动画效果，使用控件蓝图，输出代码和布局建议" | 清晰详细，结果更好 |
