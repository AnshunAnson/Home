# Niagara AI 特效助手

## 📌 一句话定义

结合 Niagara 和 AI Agent，实现自然语言生成粒子特效、智能参数调优的工具。

## 🎯 核心概念

1. **Niagara 模块脚本**: 可编程粒子系统
2. **SDF 采样**: 距离场驱动粒子行为
3. **AI 参数推荐**: 基于效果描述推荐 Niagara 参数
4. **智能预设**: AI 学习偏好，自动生成个性化预设

## 💡 应用场景

### 1. 自然语言生成粒子
```
输入："一个发光的水母，带着蓝色的尾迹"
AI 生成：
- Niagra System 配置
- Sprite 替换为带 Alpha 的纹理
- 添加 Point Gravity 向外扩展
- 配置 SDF 碰撞球体
```

### 2. SDF 驱动特效
```
您的 Niagara SDF 技能可实现：
- 粒子沿 SDF 表面流动
- SDF 距离触发粒子颜色变化
- 碰撞反弹基于 SDF 计算
```

### 3. 智能调参
```
AI 观察：
当前：粒子寿命 2s，速度 100
效果：粒子过早消散
建议：寿命调整为 4s，速度降低至 60
```
