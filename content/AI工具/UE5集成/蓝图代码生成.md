# 蓝图代码生成

## 📌 一句话定义

利用 AI Agent 将自然语言描述转换为 UE5 蓝图节点，或自动优化现有蓝图逻辑。

## 🎯 核心概念

1. **自然语言 → 蓝图**: 描述功能需求，AI 生成对应蓝图结构
2. **蓝图 → 解释**: 上传蓝图截图/代码，AI 分析并给出建议
3. **蓝图优化**: AI 检测性能问题，提供优化方案
4. **节点推荐**: 根据上下文智能推荐下一个节点

## 💡 使用示例

### 输入
```
"创建一个拾取系统：
- 玩家碰撞球体时触发
- 显示拾取特效（Niagara）
- 播放音效
- 增加分数并显示UI"
```

### AI 输出
```
Event ActorBeginOverlap → Cast to PlayerCharacter →
Branch (IsValid) →
Spawn Niagara System →
Play Sound at Location →
Add to Score →
Update UI Widget
```

## 🔧 工具方案

| 工具 | 输入方式 | 输出 | 精度 |
|------|----------|------|------|
| ChatGPT | 文字描述 | 蓝图结构文字 | 中 |
| Copilot | 代码/注释 | 蓝图建议 | 中 |
| UE5 Assistant | 对话界面 | 蓝图节点 | 高 |
| 自定义 Plugin | API | 蓝图 Asset | 高 |
