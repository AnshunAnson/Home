# UE编辑器

## 📌 一句话定义

UE编辑器开发工程师负责为 Unreal Engine 5 设计和实现工具、编辑器扩展和工作流自动化，提升团队开发效率。

## 🎯 核心概念

1. **Editor Utility Widgets (EUW)**: 使用 Slate/UMG 创建编辑器内工具界面
2. **Python scripting**: 通过 PySide2+UE Python 实现工具
3. **Editor Module**: C++ 编辑器模块开发，自定义 Asset/Importer
4. **Commandlet**: 命令行批处理工具，自动化重复任务

## 💼 行业信息

### 岗位职责
- 开发 UE5 内置工具（骨骼编辑器、动画工具、材质编辑器）
- 制作资产处理流水线（批量导入、格式转换）
- 实现编辑器扩展（自定义 Details Panel、Asset Browser 插件）
- 优化美术/策划工作流，提升团队效率
- 编写工具文档和培训材料

### 技能要求
- 精通 C++ 和 UE5 框架
- 熟悉 Slate/UMG UI 开发
- 了解 Python/BLE 扩展开发
- 有 Editor Module 开发经验
- 熟悉资产导入管线 (FBX、Alembic、USD)

## 💡 应用场景

- 游戏工作室内部工具链
- 影视资产处理流水线
- 虚拟制片工作流
- QA 自动化测试工具
- 关卡设计师辅助工具
