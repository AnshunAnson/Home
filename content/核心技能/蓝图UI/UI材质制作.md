# UI材质制作

## 📌 一句话定义

使用 UE5 材质系统为 UI 创建特殊效果，如玻璃质感、发光效果、动态纹理等。

## 🎯 核心概念

1. **UI 材质特点**:
   - Masked/Transparent 混合模式
   - 采样 UI Texture
   - 与 UMG 的 Image 组件配合
   - 参数化可动态调整

2. **常用 UI 材质效果**:
   - 玻璃/毛玻璃效果 (Dither + Depth Fade)
   - 发光/光晕 (Emissive)
   - 扫光/流光 (UV 动画)
   - 描边/阴影 (Post Process)

3. **材质实例化**:
   - Material Instance Dynamic (MID)
   - 运行时修改参数
   - 性能优化
