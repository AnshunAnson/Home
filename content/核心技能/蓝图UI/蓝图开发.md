# 蓝图UI开发

## 📌 一句话定义

使用 Blueprint 可视化编程开发 UI 交互逻辑，包括按钮事件、界面切换、数据绑定等。

## 🎯 核心概念

1. **Widget 蓝图通信**:
   - Event Dispatcher: 事件分发
   - Cast to: 类型转换获取引用
   - Get User Widget Object: 获取实例

2. **常见 UI 逻辑**:
   - 按钮点击事件
   - 界面切换/堆栈管理
   - 数值绑定/更新
   - 输入框处理

3. **性能优化**:
   - Object Pooling: 对象池复用
   - Event Driven: 事件驱动
   - Lazy Load: 延迟加载
