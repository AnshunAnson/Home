# UMG基础

## 📌 一句话定义

UMG (Unreal Motion Graphics) 是 UE5 的 UI 开发框架，用于创建游戏界面、HUD、菜单等 2D 用户界面。

## 🎯 核心概念

1. **UMG 构成**:
   - Widget: UI 组件 (Button, Image, Text, Slider等)
   - Widget Blueprint: 可视化设计 UI
   - Anchor: 锚点系统，适配不同分辨率
   - Animation: 组件级别动画

2. **布局系统**:
   - Canvas Panel: 自由定位
   - Horizontal/Vertical Box: 线性布局
   - Grid Panel: 网格布局
   - Overlay: 层叠布局

3. **样式系统**:
   - Style: 可复用样式
   - Theme: 主题配置
   - Font: 字体管理
